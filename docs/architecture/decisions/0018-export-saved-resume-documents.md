# ADR-0018: 导出已保存的简历文档

- Status: Implementation candidate
- Date: 2026-11-11
- Decider: 用户已授权简历导出主线；本记录说明实现边界。
- 依据：用户确认在面试训练记忆后推进简历导出；现有简历编辑、派生版本和上传原文保留契约。

## Context

简历的上传原件、旧提取原文和用户后来保存的岗位版本可能不同。直接下载原件会遗漏定制内容；拼接原文会把已删除或改写的内容重新放回导出。上传简历复制后来源可能变为 manual，但旧 `raw_text` 仍存在，不能用来源标签判断其是否可投递。

## Decision

只从用户保存的 `content_json` 白名单结构字段及 `additional_text` 投影生成 PDF/DOCX。`raw_text`、`parsed_data`、原文件路径和导入审阅元数据不输出，也不作为缺失内容的回退。编辑器的“其他”明确写入 `additional_text`；历史原文只读保留，不自动迁移。

导出先生成实际 PDF 供核对，再以来源指纹下载 PDF 或可编辑 DOCX。未保存编辑或保存中不能导出，不隐式保存。指纹绑定 schema、简历 ID、标题、语言及除旧原文/导入元数据外的完整保存内容；渲染前后重读，变化拒绝并要求刷新。缺失、软删、未知结构、超限或字体缺字明确失败，不静默截断。

输出使用本地 fpdf2 / python-docx，不调用模型或外部转换服务，不写数据库，不保存生成文件，不发送材料，也不确认已投递。HTTP 保持现有认证，响应禁止缓存；前端以鉴权请求取得 Blob，不把凭据放到 URL。关闭或切换版本/语言后取消旧请求、销毁渲染任务和文档，并释放下载临时 URL。实际 PDF 预览使用随前端打包的 PDF.js worker 和单页 Canvas，兼容桌面现行 `frame-src/object-src none`，不放宽 CSP；禁用 eval、外部资源及字体注入。当前页成功渲染后才可声明核对，渲染失败不能下载。

PDF 内嵌随包的 OFL Noto Sans SC 静态字体，支持可选择中文和自动分页，无运行时下载。DOCX 与 PDF 使用同一内容投影，段落可编辑；本机字体和 Office 软件可能改变 DOCX 分页。wheel 和 frozen 包显式包含字体、许可证与 DOCX 模板。

## Consequences

用户下载的是核对过的保存版本，旧原文不会悄然泄入。字体增加安装包体积；受支持字段之外的数据需先整理，不能把任意 JSON 当作可公开简历。导出本身不表示内容真实性或投递成功。无迁移或破坏性变化。

## Alternatives Considered

- 下载上传原件：保留原始版式，但无法体现后续保存的定制内容，继续作为独立原件功能。
- 浏览器截图/打印：实现轻便，但图片不利于选择、检索和稳定分页。
- 云端文档转换：引入简历外传、运行时网络和费用，不符合本地导出边界。
- 全量 JSON 或原文拼接：可能混入内部元数据、旧信息及未审阅内容，拒绝采用。
