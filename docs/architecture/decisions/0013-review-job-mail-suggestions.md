# ADR-0013：求职邮件的有界同步与独立审阅

- Status: Implemented, synthetic validation in progress; real mailbox activation blocked
- 日期：2026-10-09
- Decider：用户确认在独立分支实施产品方案 v0.2，默认手动同步
- 依据：master `5b9605bab343c4f95ede2c0c61ecd47bb7d923a1`、产品确认稿 v0.2、[ADR-0012](0012-bound-local-proactive-jobs.md)

## Context

求职邮件是外部、不可信来源，不能构成 Agent 指令或业务写授权。已有
ApplicationEvent 要求具体开始时间和正时长；创建事件不改变投递阶段。
邮箱同步需要独立游标、读取范围与候选预算，不能复用投递主动任务表冒充收信队列。

## Decision

新增 `job_mail` 模块与增量表，不破坏已有投递、事件或 Offer 模型。
设置管理同步；今日提醒展示独立邮件待确认区，原流程提醒不变。
默认手动，连接不读正文；自动可选，间隔 5–1440 分钟、初值 15 分钟。
关闭自动不取消当前任务、不禁止手动；取消当前任务不改变未来自动计划。

每工作区一个连接，明确选择目录。手动/自动共用 SQLite admission、持久 lease、
60 秒节流、日候选上限 100、目录 UID/UIDVALIDITY 游标与内容/来源去重。
每目录每次最多 50 条，不补跑遗漏调度次数；余量明确延期。
仅后端持续运行时检查。失败不显示“没有新邮件”，连续三轮失败关闭自动并保留手动。

识别与业务写分离。默认离线规则是测试与降级通道，不是完整语义识别的替代承诺。
可注入模型适配仅接收有界清洗文本、固定输出 schema 与原文 span，无工具权限、
无全局 provider fallback；明确 provider/destination/text 授权缺失时在调用前拒绝。
识别预算先持久预约，再在数据库事务外调用；未知结果保留人工核对来源，不自动重试。
手动粘贴在本批固定使用离线规则，不继承任何注入的模型配置。

本批仅完整时间和正时长的事件新增、明确地点补充更新。测评为
`written_test + subtype=assessment`。截止、窗口、时间未定、Offer、取消、复杂改期
只提供人工建议，不虚构时长/午夜，不改变投递阶段，不发送任何邮件。

审阅是明确用户 API，不注册成 Agent 工具，不服从聊天自动批准。
服务端预览绑定建议版本、最终编辑字段、目标投递/事件完整快照和范围版本；
确认必须带明确批准、同一请求与预览 token。SQLite `BEGIN IMMEDIATE` 内再次校验，
复用事务内事件 repository，原子写事件、建议状态及唯一操作回执。
同操作同内容返回原回执；未知提交只能先查回执，客户端关闭不视为批准。
更新仅提交已审字段，保留未提及备注；开始时间改变时旧提醒清除须列入确认摘要。

显式调整范围时，仅上一范围且仍在所选目录内、原文未清理的未处理建议升级版本；
旧预览失效，须重新审阅。移出后再加入、断开重连不凭历史位置复活，需实际重读。
确认后回执与业务记录不因断开、删源片段或源邮件消失而删除。
待审片段最长 90 天、已处理片段 30 天，旧预览同步失效；遗留识别 attempt
片段最长 90 天，保留禁止自动重试的来源指纹。

## Security and activation gate

真实 QQ 与外部 AI 默认关闭，当前 UI 不收授权码，不调用真实服务。
QQ 适配只允许 `imap.qq.com:993`、验证 TLS、只读 SELECT 与 BODY.PEEK，
不支持 SMTP、任意 host、移动/删除/标已读；读取正文前核对日期范围。
OS vault 仅允许 Windows Credential Manager、macOS Keychain、Linux Secret Service；
不可用不降为明文。该适配尚待安全输入/凭据写入与删除流程、认证部署、
QQ 文件夹编码/身份、真实邮箱联调，不得宣称实邮箱可用或全验收完成。
真实候选片段发送外部模型仍须另获数据与具体目标授权。

## Consequences

邮件证据、建议和回执可恢复且不会绕过人工确认。现有手工流程保持兼容。
严格范围撤回可能令旧建议需要重新读取或手动导入，界面应说明原因。
本批不提供跨设备托管、附件/OCR、全文归档、自动发信或自动接受 Offer。
尚无真实邮箱与真实模型质量指标；合成样本通过不能推导真实识别率。

## Alternatives considered

1. 自动把邮件写入日程：会把不可信内容当作授权，无法满足强制审阅与并发保护。
2. 复用 ProactiveJob/聊天确认开关：缺邮箱范围与长期游标语义，且会混淆独立授权。
3. 首批同时迁移截止/窗口/取消领域模型：影响日历与旧客户端兼容，按用户确认分批。
