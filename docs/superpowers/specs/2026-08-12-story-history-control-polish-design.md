# 岗位资料历史与面试故事控件精修设计

状态：已获用户口头批准，待书面复审

## 目标

在不改变 OfferPilot 现有三栏布局、路由、数据流和业务语义的前提下，修复岗位资料历史的长文本横向溢出，并提升面试故事库列表、版本正文、证据引用和操作控件的可读性。验收截图使用中文、亮色模式和 `1455×1200` 宽屏视口。

## 范围

### 岗位资料历史

- 保留现有 Modal 和版本详情读取逻辑。
- 桌面宽度调整为适合阅读岗位文本的 680px，并受视口宽度约束。
- 版本选择项不再依赖 Ant Design Button 的单行文本布局，改为可换行的整行选择控件。
- 每项明确展示版本号、来源类型和多行摘要；中英文混排、长 URL、连续英文技术词均不得越出卡片或 Modal。
- 详情正文保留原换行并允许任意长 token 安全折行，继续保持只读。
- 加载、空状态和选中状态均保留，不新增请求或写入。

### 面试故事库

- 保留页面位置、最大宽度、顶部动作区、列表与版本详情的纵向结构。
- 状态筛选收口为一致的分段式控件视觉；搜索、新建、返回等控件继续使用现有回调。
- 故事列表增加清楚的行容器、标题/状态/版本/来源层级和统一操作按钮，不改变归档、恢复、查看版本行为。
- 版本正文按“适用问题、情境、任务、行动、结果、复盘”等既有内容类型分段展示；只使用版本中已有的稳定 ID 和文本，不重新解释或生成内容。
- 证据不再以大量重复 Tag 平铺。顶部显示来源与引用数量；每个事实目标下用原生 `<details>` 展示对应冻结引用，完整摘录保持纯文本。
- 来源 `current / changed / missing / frozen_user_assertion` 继续沿用现有状态语义；不新增推断、评分或写入。
- Pilot 右栏和全局页面布局不在本次修改范围内。

## 视觉规则

- 沿用现有紫色品牌色和浅色中性背景，不增加渐变或新的颜色体系。
- 卡片圆角、按钮高度、边框和阴影使用现有控件 token；嵌套圆角遵守外层大于内层的规则。
- 标题使用平衡换行，正文使用自然换行；动态版本号使用等宽数字。
- 链接式操作补足至少 40px 点击高度，并提供明确 hover、focus-visible 与 active 状态。
- 宽屏保持当前纵向信息流；窄屏仅让操作区、正文对照和证据摘要自然堆叠，不新增响应式布局结构。

## 无副作用边界

- 不修改后端、API、数据库、AI、Provider、证据校验、幂等或 CAS。
- 不修改 Story/JD 类型与 service 接口。
- 不发起新增读取或写入请求。
- 不自动展开证据、不写日志、不渲染 HTML；所有用户与 Provider 文本按纯文本展示。

## 测试与验收

- 先补失败测试，证明长中文、英文技术词与 URL 的版本摘要具备可折行容器，且版本详情正文不会横向溢出。
- 挂载真实面试故事库，验证列表层级、稳定操作、STAR 分区、证据数量聚合和逐目标 `<details>`；归档、恢复、版本读取调用次数保持不变。
- 断言面试故事页面不会新增写 service、AI 或导航副作用。
- 运行相关前端测试、TypeScript、生产构建和 `git diff --check`。
- 使用中文合成数据在亮色 `1455×1200` 浏览器中逐页检查岗位资料历史和面试故事库，确认无横向溢出、无遮挡、无控制台错误，并输出新截图。
