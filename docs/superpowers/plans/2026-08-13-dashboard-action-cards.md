1. 为周状态摘要派生函数和两个真实组件补充失败测试，固定摘要、行值、标签和现有导航回调。
2. 重构 `WeeklyMissionPanel` 为单张本周关键事项卡，补齐响应式、焦点、减少动态效果和深色模式样式。
   - 查询尚未完成、失败或只有部分覆盖时，显式标记对应指标与总体摘要为数据暂不可用。
3. 收口 `InterviewV01View` 的下一项训练卡，加入来源、短时训练提示和无自动写入边界标签。
4. 运行定向测试、TypeScript、生产构建和 `git diff --check`。
5. 用中文亮色宽屏完成实际浏览器走查，保存两张截图及验收报告。
6. 进行独立代码复审，修复所有 P0/P1/P2 后提交；不推送、不合并。
