本轮仅新增评估材料与测试，不改变检索规则；PR #73 保持 Draft，依赖 #72，不改 base、不合并。

## 方法和边界

- [固定样本](../../evals/fixtures/memory-retrieval-exploratory-v1.json)：16 条合成记忆、26 条查询；
  面试、岗位、简历、混合需求、同义表达、旧未分类记录、技术词、泛聊、准备绑定、否定、无命中、超长条目。
- 3 个确定性 ID 排列（seed 0/7/19）× 3 个字节预算（1024/2048/4096）× 2 个策略，468 次投影。
  每种策略 234 次。相同文本池和人工相关性标签；ID 与业务含义分离，不只把目标放最后来证明收益。
- 标签由实现者在看到算法后编写，属于探索集，**不是盲测、独立人工标注或真实用户样本**。
  各查询没有按真实流量加权；三个 ID 排列不是三个独立用户，不能计算可信总体提升或置信区间。
- 使用已经符合生命周期条件的候选池；本评估不测数据库权限、删除或期限，也不替代既有安全回归。
  无模型、无网络、无真实用户数据；测选择和 contributor 预算，不测最终总预算裁剪或模型是否正确使用。
- 旧基线按 ID 取全部有效记录，用现有 `_contributor` 原子预算逻辑；新策略调用 `select_memory` 后
  使用相同逻辑，并计入实际新增 `source_revision` 的封装开销。基线不偷偷获得新排序或去重。
- 重复 remote/remote_copy 属同一语义组，召回只记一次；重复仍消耗字节并单独统计。
  为使“无命中应返回空”可判定，池中不含全局语言偏好；其跨场景保留仍由单独产品回归覆盖。

## 指标

召回为每个有相关标签的 trial 的命中语义组数/相关组数，再宏平均；空标签不混入召回。
无关比例是全部返回条目中不在相关组的比例，重复条目仍计入返回数。
无命中准确率为两条空标签查询的 18 次 trial 返回空的比例。
平均字节为实际 canonical 消息字节加分隔开销，不是 token 数。

“单条可装入召回”从分母去掉连单独放入新策略封装也超预算的相关条目，**不是联合装箱最优召回**；
避免把不可装入的长条目全算成排序失败，不能借此隐藏长记忆未被消费的产品限制。

| 指标 | 旧 ID 截取 | 新场景词法 |
|---|---:|---:|
| 宏平均召回 | 54.90% | 60.58% |
| 单条可装入宏平均召回 | 59.40% | 65.24% |
| 返回条目无关比例 | 79.83% | 39.41% |
| 返回条目重复比例 | 6.41% | 0.00% |
| 无命中返回空 | 0/18 | 18/18 |
| 平均消息字节 | 2165.33 | 904.56 |
| 平均预算占用 | 93.39% | 45.06% |

更低预算占用可能同时来自正确省略和错误漏召回，不能单独当质量收益。

| 预算 | 旧召回 | 新召回 | 旧单条可装入召回 | 新单条可装入召回 |
|---|---:|---:|---:|---:|
| 1024 | 23.76% | 50.14% | 25.60% | 53.27% |
| 2048 | 48.62% | 64.68% | 52.60% | 69.94% |
| 4096（默认） | 92.32% | 66.92% | 100.00% | 72.52% |

## 保留的失败样例

以下取 seed=0、预算4096；完整逐例命中、missing、unwanted 与字节在脚本 JSON 中。

| 查询 | 实际失败 | 原因/边界 |
|---|---|---|
| 在家上班适合我吗 | 漏掉 remote，空返回 | 同义词表覆盖“居家办公”但没有“在家上班” |
| 聊聊我的薪酬期望 | 漏掉目标年薪；召回远程偏好 | “年薪”未归入薪酬词表，共有“期望”造成弱词法误选 |
| 今晚吃什么 | 漏掉“喜欢清淡的晚餐，不吃花生” | “今晚/吃什么”与“晚餐”词法不相交，不能做语义推断 |
| 咱们接着练吧（准备已绑定） | 空返回，漏掉准备相关组 | 为防无关请求继承场景，承接白名单有意保守；不是完整意图理解 |
| 不要推荐远程职位，我只想聊园艺 | 返回园艺，但额外返回9个无关组 | 场景词与别名不理解否定；软分类权重仍放入岗位类内容 |
| Kafka 面试怎么讲项目 | 两个相关组均命中，但额外返回6个组 | 粗分类能补召回，也会引入具体题目不需要的其他项目/目标 |
| 准备面试 | 漏旧未分类 Redis 和超长经历；额外返回目标 | 无词面重合的未分类内容无场景分；不能自动重分类 |
| 大型迁移项目 | 唯一相关条目始终未进入消息，返回其他项目/准备 | 该条目超过全部三个预算，原子省略符合安全契约；两策略召回均为0 |

混合需求的宏召回从55.56%降至50.93%；同义表达从73.41%降至39.68%；准备绑定组从47.22%
降至19.44%。这不是随机波动证明，而是该固定探索集暴露的覆盖缺口。旧基线在宽预算通过大量
无关内容“顺带命中”；新策略则牺牲了其中一些相关内容，必须同时看两项指标。

没有据此直接添加所有样本关键词或放宽准备绑定。否定、词法弱信号、分类粒度与未分类召回是
需要用额外独立样本比较的策略取舍；未发现新的删除/授权/预算绕过。不要将本轮失败都改成测试
期望以刷绿，也不要用返回全部记忆的降级掩盖缺口。
