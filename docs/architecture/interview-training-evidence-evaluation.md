# 训练证据：小样本验收矩阵

本矩阵验证本地确定性行为，不是“学习效果已提升”的报告。实现范围见
[ADR-0017](decisions/0017-bound-interview-training-evidence.md)。真实用户效果与模型对照尚未运行；
本版不调用模型，不沿用历史费用授权。

## 行为样本

每个样本使用临时数据库与合成回答，不上传用户面试内容。验收既看返回结果，也看保存状态。

| 场景 | 不使用训练证据时 | 使用证据后必须满足 |
| --- | --- | --- |
| 旧完成回答没有辅助信息 | 只有回答/自评 | 条件未知，不自动导入、不从文字推断 |
| 用户明确记录独立作答 | 通用练习 | 引用该记录与条件，仍不宣称掌握 |
| 用户记录提示后作答 | 通用练习 | 建议换情境独立尝试，不声称已掌握 |
| 用户看过答案后作答 | 通用练习 | 明确参考条件，不等同独立表现 |
| 用户记录条件未知 | 通用练习 | 不猜测辅助条件，提醒下次记录 |
| 两个情境之间切换 | 固定旧 drill | 题目切换，旧回答/日期可追溯 |
| 更正辅助条件 | 旧信息可能误导 | 只使用新版；说明是条件更正而非能力变化 |
| 撤回一条记录 | 无撤回语义 | 新证据正文清空，建议不再引用；原 Plan 不变 |
| 来源变更/撤回/删除 | 旧 Plan 仍可能可读 | 暂停新建议与新保存，不把可读历史当当前证据 |
| 目标或投递失效 | 历史列表可能仍有记录 | 不跨投递消费；删除投递后不可读 |
| 相同命令重试/冲突 | 可能重复保存 | 相同输入重试不重复；同 key 改内容、旧 revision 冲突 |
| 切页或网络结果未知 | 可能迟到覆盖 | 原命令可恢复，旧页面结果不能更新新计划 |

自动化通过只能证明这些边界，不证明回答正确或推荐有用。真实用户试用应另记录：
推荐是否与当前目标有关、是否减少重复、能否理解引用依据、纠正后是否恢复信任。
若后续接入模型，应固定同模型与预算对照，有/无证据各跑相同样本，人工盲评
pass/fail/abstain；不把模型自己的评分当作能力事实。

## 自动化入口与待验收项

- 后端：`tests/test_training_evidence.py`（来源/目标失效、归属、四种条件、事务回滚、CAS/幂等、撤回与迁移）。
- 前端：`TrainingEvidencePanel.test.tsx` 与 `AdaptiveInterviewPracticeWorkspace.test.tsx`，
  覆盖显式保存、冲突、未知响应原键恢复、StrictMode、切页迟到与跨宿主历史计划恢复。
- 上层保护：`AppShell.adaptivePracticeGuard.test.ts`、`retainedWorkSafety.test.ts`，
  验证待确认命令不能被当作可丢弃普通草稿。
- 尚待：真实浏览器视觉走查、完整发布门禁、真实用户收益对照。
  DOM 交互测试或构建通过不替代上述验收。
