# ADR-0020：按当前任务检索个人记忆的词法基线

- Status: Proposed（小步候选；离线契约验证不代表真实模型质量或可发布）
- 日期：2026-11-18
- Decider：用户已授权按场景检索阶段；不含合并或部署
- 依据：[Knowledge 架构](../knowledge-system.md)、[分类与期限](0019-version-memory-metadata.md)

## Context

PR #72 的 `fe85e0ce` 已提供用户确认分类与期限，但召回仍按 ID 取全部有效记录，再按预算裁剪。
相同预算可能让无关记忆挤掉当前任务需要的项目或目标。本轮基于 #72，合并前必须对齐 master。
MemoryRepository 当前属于单一已认证工作区，最多 100 条未删除记录；没有用户 ID 列，不能假装
新增了多租户授权。跨工作区依靠各自数据库/loader 隔离，检索不接受调用方指定 owner。

## Decision

1. 保留会话/投递范围校验、独立开关、当前 active 版本、元数据严格验证、到期排除及只读快照。
   先校验全部候选再相关性筛选；损坏元数据不能因不相关而被隐藏。临时不可用仍省略可选来源，
   完整性错误仍失败关闭；没有“退回全部记忆”路径。不修改写入、CAS、删除或备份结构。
2. 当前请求最多 500 字符，NFKC/casefold 规范化。英文词、中文双字片段及小型显式同义词表作
   词法信号；面试/岗位/简历关键词产生软分类权重。词法命中可跨分类召回，旧未分类记录仍可命中。
   多场景取分类最大权重，不把混合需求强行归入一个场景。不是 embedding 或语义检索。
3. 当前请求完整匹配有限承接短语（如“继续”“帮我准备一下”）时，可使用本次已启用、已校验并实际装配的 Readiness contributor
   作为面试后备提示。明确当前请求优先。未启用、空、失效绑定不产生提示；不从页面标题、图谱、
   历史 assistant 文本或未经校验的绑定猜测。明确无关请求、空请求、包含其他主题的长句不借用准备场景；其他可信页面场景尚未接入。
4. 明确 preference 分类中描述回答/回复/表达语言或长短的有限词汇可跨场景保留；不把所有偏好
   当全局指令。该规则只是相关性判断，不持久化推断，不改变“当前请求优先/历史非授权”封装。
5. 词法每项 4 分（最多 6 项）、同义概念每项 4 分、分类 1–3 分、表达偏好 1 分；正分才入选，
   可返回空。权重是待评估基线，不是质量承诺。不按确认时间衰减，没有把旧记录自动视为失效。
   全候选排序后以 ID 稳定打破平分；只去除规范化正文、分类和期限均相同的重复项。
6. 继续使用既有 contributor 字节预算和总投影预算，整条省略、不截断正文。没有另设结果条数
   截断，因此大条目装不下时后续小条目仍有机会。图谱仍是同一库的管理界面。
7. 内部诊断仅存策略版本、候选/理由/重复计数和场景布尔值；固定理由码及 `memory_retrieval_v1`
   进入现有 manifest signals。计数是预算前候选决策，不证明最终注入；最终来源/状态沿用投影审计。
   查询词、正文、实体名称不进入诊断。source revision 标识检索策略；不新增正文 trace 数据库。

## Consequences

不增加依赖、模型调用、持久表或数据迁移。候选最多 100 条且保留 loader deadline。
代价是词法歧义、否定句、短查询和词表外同义词可能误选/漏选；分类本身较粗，类别命中不保证
具体岗位/项目相关。缺少明确请求或有效准备绑定时允许空，不能宣传为完整页面感知能力。

## Alternatives Considered

- 原有效记录按 ID 截取：保留为离线比较基线，不满足任务相关性目标。
- 只按分类硬筛选：会漏掉跨场景和旧未分类的有用记录。
- 直接引入通用记忆框架、GraphRAG 或模型重排：当前规模无需新增基础设施，且不能替代用户
  确认、期限、删除与来源边界。未来是否加入向量应由独立查询集对照决定。

## Verification

合成测试覆盖面试、岗位、简历、泛聊、混合请求、无命中、旧未分类记录、中文同义词、跨分类、
表达偏好、可信准备提示、当前请求优先、重复、同预算 ID 基线、工作区隔离与删除/过期保护。
同预算案例证明构造的 Kafka 任务从被园艺记录挤出变为保留；不将单个样本推广为整体质量提升。
后续探索性对照见 [26查询合成评估](../memory-retrieval-evaluation-v1.md)：默认预算召回下降，不能宣称全面提升。
后续 [V2冻结独立验证](../memory-retrieval-evaluation-v2.md) 未通过：候选降低噪声但损失必需召回，未接入运行时。
仍需独立标注查询集，对比相关项召回、无关项比例、预算占用和排序稳定性，再定质量阈值。
没有真实用户数据或付费模型验收。具体执行结果见本次 PR，不把计划当已通过证据。
