# 跟着一个求职助手，看懂 Agent 怎么工作

你不需要先知道 Agent 是什么，也不需要会写代码。我们从一件熟悉的小事开始：让 AI 帮你记下一场面试。

OfferPilot 是一个开源求职工作台。这组内容借它的具体场景，带你看懂 AI、程序和人怎样配合完成任务。

## 第一次来，先读四篇

**[01 看一次新增日程](01-record-an-interview.md) → [02 找到信息来源](02-where-information-comes-from.md) → [06 理解继续与等待](06-how-a-task-continues-and-stops.md) → [07 看清四方分工](07-who-connects-the-steps.md)。**

这条短路线围绕同一组虚构投递和同一场面试：云岚数据 · 测试开发，2026 年 10 月 15 日北京时间 15:00，线上，60 分钟。先看懂请求怎样借助资料、工具和确认变成一条记录。教学问答用来解释分工，不冒充真实模型原话；实测素材另有标注。

读完后试着解释：谁提出保存建议？谁实际保存？为什么要确认？只听到“记好了”够不够？能说清这些，就可以先停在这里。无需安装项目、配置模型或支付调用费用。

## 按问题继续查阅

想细看确认、追问和结果核对，读第 3—5 篇；想处理失败、中断和权限，读第 11—17 篇；想回顾全貌，打开[第 22 篇职责地图](22-putting-the-harness-together.md)。全部 22 篇保留在下面，不要求先读完才能进入下一层。

想动手时，可先跑[不需要模型密钥的小实验](examples/README.md)，再进入[六篇 Harness 进阶导读](advanced/README.md)，逐步对照源码、设计记录与测试。

## 你可以学到哪一层

| 想做什么 | 怎样开始 | 当前提供的内容 |
| --- | --- | --- |
| 先看懂 | 看例子和图，用自己的话说说发生了什么 | 第 1—22 篇与收尾总览已提供；作者图文校对已完成，尚未读者试读 |
| 再体验 | 在准备好的演示里试试确认和取消 | 交互演示尚未提供，不影响阅读这些文章 |
| 想自己实现 | 有简单 Python 与接口基础后，按专题追踪真实实现 | [独立小实验](examples/README.md)与六篇源码导读已提供；小实验只用 Python 标准库，产品源码测试另需开发依赖 |

看懂一个功能就是有用的收获，不必一次学完所有层次。自己实现完整系统需要逐步学习编程，这不是阅读入门文章的前提。

入门篇都有一个小问题和可展开的参考回答。不必背术语，先试着用自己的话解释刚刚发生的事情。第二十二篇是概念路线的收尾；之后可以进入[进阶路线](advanced/README.md)，看同样的问题怎样落到源码和验证。读懂这些职责，不等于已经学会所有实现细节，也不要求每个项目都用上所有扩展。
