# 简历事实补充工作台浏览器验收

日期：2026-08-12
分支：`feat/20260812-resume-fact-workspace`

## 场景

使用隔离临时数据创建中文候选人“筱哲”的完整结构化简历，在亮色宽屏界面完成：

1. 简历库打开简历编辑页；
2. 打开“简历事实体检”；
3. 从“可补充真实事实”进入事实补充工作台；
4. 核对原文和 JSON Pointer；
5. 手工填写经确认的新表述并勾选真实性确认；
6. 创建派生版本并保存；
7. 自动打开版本差异，父简历自动成为基准；
8. 回读修改前、修改后和差异摘要。

## 结果

- 原简历保持不变，新版本的 `parent_resume_id` 指向原简历。
- 仅替换 `/experience/0/highlights/0`，差异摘要为“修改 1”。
- 未配置或调用 AI，未触发 Pilot、JD、投递、材料、面试或 Knowledge 写入。
- 浏览器控制台错误为 0。
- 页面与 API 均为本地 `127.0.0.1` 服务。
- 浏览器标签、服务进程、端口和两次隔离临时数据目录均已清理。

## 发布前验证

- 前端全量 Vitest：退出码 0。
- 功能定向回归：103 passed；最终恢复边界回归：13 passed。
- TypeScript、生产构建、`git diff --check`：通过。
- 独立代码复审：无 P0/P1/P2。
- 复制或保存结果未知时会冻结并重新加载，不猜测副本，也不打开响应前的旧内容。
- 编辑器存在未保存草稿时不会发起事实补充；字段恢复为保存值后可正常继续。
