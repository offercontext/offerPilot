## 范围

`cases.json` 固定五组十二回合，覆盖工作/闲聊切换、人设与用户事实隔离、
改人设后的已有约定、未来提议与第三方经历、来源删除与退出参与。
普通对话走实际 `/api/pilot/runtime/v1/turns` 并读取持久终态；控制操作走实际端点。
入口标签仅说明拟用场景，**本次不执行 Web，不是 Web 到 provider 闭环验收**。

仅合成隔离数据，不读取真实用户资料。每回合一个 Broker 票据，全批最多十二次
上游调用（包括任何标题、重试、工具循环）；每次最多 512 输出 token、90 秒，
整批 20 分钟。无 fallback、retry、续写、搜索、抓取或工具调用执行。
技术、状态、预算、截断或工具返回异常即停；语义和自然度在完成后独立逐条审阅。
机械通过不是语义通过，不给准确率或长期稳定性结论。

x08 保留原问句，当前产品未为该措辞返回专用 companion context。
工件必须保留实际空投影、可见历史与持久状态，不能把仅用于核对前提的规范查询
塞进模型上下文或当作模型已经看到的证据。
